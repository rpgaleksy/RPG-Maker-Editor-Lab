# Flowboard Project Status Addendum

This file activates and configures `FLOWBOARD_POLICY.md` for one selected
repository. Record verified project facts and deliberate exceptions only. Blank
fields grant nothing. This addendum authorizes no commits, tracker changes,
cross-repository writes, publication, deployment, or interactive editing.

## Integration

```text
Compatible policy revision: 2026-09-13
Integration state: planned
Stable project ID: rpg-maker-editor-lab
```

The project ID must match `.flowboard/project.json`. Schema compatibility is
declared in that file and enforced by the Flowboard tool.

## Sources and updates

```text
Authoritative task tracker: AGENTS.md default local Markdown tracker under coordination/; no tracker records are currently present
Authoritative technical/status sources: README.md; docs/investigation.md; docs/references.md; VERSIONING.md; accepted decisions and verified repository evidence
Reconciliation owner: policy default
Update mode: user-requested
Boundary override: none
Project-specific completion rule: For compatibility claims, successful startup alone is insufficient; original file formats, EasyRPG extensions, and Windows patches must be assessed separately, with applicable checks and results documented.
```

Flowboard remains a projection of these sources. An owner identifies
responsibility but does not override `AGENTS.md` write ownership or permissions.

## Audience

```text
Local audience: User and configured project team; local/internal only
Approved stakeholder audience: none
Evidence visibility and explicit exclusions: Use concise summaries of repository documentation and verified evidence. Exclude secrets, externally supplied originals, proprietary editor programs, DLLs, RTP, game assets, extracted or decompiled third-party content, private external analysis working copies, and unapproved claims.
Publication state: not approved
```

Change publication state only through a separately approved delivery plan under
the destination's web policy.
